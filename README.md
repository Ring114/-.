 # 🧪 Генератор тестовых данных пользователей (LLM)

Консольный Python-скрипт для генерации **фейковых пользователей** с реалистичными биографиями.  
Подходит для **тестирования баз данных**, учебных проектов и демонстрации работы с LLM.

Скрипт может работать:
- **без LLM** (шаблонные биографии),
- **с LLM (Grok / xAI)** — для генерации реалистичного текста.

---

## 📌 Возможности

- Генерация пользователей со следующими полями:
  - `name` — имя и фамилия  
  - `email` — уникальный email  
  - `age` — возраст  
  - `biography` — краткая биография  
- Транслитерация имён для email
- Гарантия уникальности email
- Поддержка форматов **JSON** и **CSV**
- Повторяемая генерация через `seed`
- Fallback-режим при отсутствии LLM

---

## ⚙️ Как работает

1. Скрипт случайно выбирает имя и фамилию из встроенных списков  
2. Генерирует возраст в заданном диапазоне  
3. Создаёт email:
   - имя транслитерируется в латиницу,
   - добавляется случайный числовой суффикс,
   - выбирается один из тестовых доменов  
4. Генерирует биографию:
   - если задан `XAI_API_KEY` — отправляет запрос в Grok API (xAI),
   - если ключ не задан или API недоступен — используется fallback-шаблон  
5. Сохраняет результат в `json` или `csv`
