# Генератор тестовых данных пользователей

Скрипт `data_generator.py` генерирует фейковых пользователей для тестирования баз данных.

Каждая запись содержит:
- `name`
- `email`
- `age`
- `biography`

## Как это работает

1. Скрипт случайно выбирает имя и фамилию из встроенных списков.
2. Генерирует возраст в заданном диапазоне.
3. Создаёт уникальный email:
   - имя транслитерируется в латиницу,
   - добавляется случайный числовой суффикс,
   - выбирается один из тестовых доменов.
4. Генерирует биографию:
   - если задан `XAI_API_KEY` — отправляет запрос в Grok API (xAI),
   - если ключ не задан или API временно недоступен — использует fallback-шаблон (скрипт всё равно завершится успешно).
5. Сохраняет результат в `json` или `csv`.

## Как запустить

### 1) Базовый запуск (без LLM)

```bash
python3 data_generator.py --count 20 --format json --output users.json
```

### 2) Запуск с Grok API

```bash
export XAI_API_KEY="<YOUR_GROK_API_KEY>"
python3 data_generator.py --count 20 --format csv --output users.csv
```

### 3) Повторяемая генерация (фиксированный seed)

```bash
python3 data_generator.py --count 10 --seed 42 --output users_seed42.json
```

## Параметры CLI

- `--count` — количество пользователей (по умолчанию `20`)
- `--min-age` — минимальный возраст (по умолчанию `18`)
- `--max-age` — максимальный возраст (по умолчанию `65`)
- `--format` — формат вывода: `json` или `csv` (по умолчанию `json`)
- `--output` — имя/путь выходного файла (по умолчанию `generated_users.json`)
- `--seed` — фиксированный seed для повторяемости
- `--model` — имя модели Grok (по умолчанию `grok-2-latest`)

Подсказка по параметрам:

```bash
python3 data_generator.py --help
```
